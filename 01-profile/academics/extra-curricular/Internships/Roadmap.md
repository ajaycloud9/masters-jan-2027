---

## 0. Where you're starting from (baseline, from your resume)

**Already strong:** Power BI, Tableau, Looker Studio, GA4, Excel (TAM/SAM/SOM), Salesforce & HubSpot CRM,
SEMrush/Apollo/ZoomInfo, Python (Pandas/NumPy/Matplotlib), SQL (query writing), A/B testing, funnel analysis,
customer segmentation, ETL workflows, KPI dashboards, AI-assisted analysis (Claude/GPT).

**Gaps the target roles keep asking for** (pulled from the 20 postings you're targeting):
statistical/predictive modeling, marketing-mix modeling & multi-touch attribution, R, cloud data warehousing
(Snowflake/BigQuery/dbt), experimentation at scale, syndicated media/audience tools (Nielsen, Comscore, Kantar
panels), survey/qual research methods, and US-style analytics-case interviewing.

This roadmap closes those gaps in the order your actual calendar allows — pre-Masters bridge, then each semester
of your program, then internship, then OPT job search.

## 3. PHASE 1 — Foundation Building (Jul 2026 – Dec 2026)

**Why this phase exists:** you finish your MMS in May 2026 but your US Masters doesn't start until Jan 2027.
This 6-month gap is pure upside — use it to close the technical gaps before you're also juggling coursework.

| Skill / Task | Why target companies want it | Resource to learn it | Proof of learning |
|---|---|---|---|
| SQL — joins, window functions, CTEs | Every single one of the 20 roles (IBM, Veeva, ADP, Amex...) lists SQL | Mode Analytics SQL tutorial (free) + StrataScratch practice | 50 solved SQL problems on GitHub |
| Python for data analysis (deepen) | Analytic Partners, Fivetran, PlayStation need real modeling, not just Pandas basics | Kaggle "Python" + "Pandas" micro-courses | 2 Kaggle notebooks published |
| Statistics fundamentals (regression, hypothesis testing, significance) | Underpins A/B testing & MMM roles (Fivetran, PlayStation, Analytic Partners) | Khan Academy Statistics + "Practical Statistics for Data Scientists" (book) | Notes + 1 mini regression project |
| Tableau Desktop Specialist certification | Signals BI proficiency for Kantar, NYT, Colgate roles | Tableau's free public training + certification exam | Certificate |
| Microsoft Power BI (PL-300) certification | You already use Power BI — formalize it | Microsoft Learn (free) | Certificate |
| Resume + LinkedIn overhaul for US market | Needed before any of the 20 applications go out | Use the resume-optimizer skill you already have access to | ATS-optimized resume + updated LinkedIn |
| F-1 visa & SEVIS prep | Non-negotiable to start the Masters on time | Your admissions-tracker checklist | Visa interview scheduled |
| GitHub portfolio scaffold | Every analytics interview now asks "show me your work" | Create a clean GitHub with README | Repo live with 1 project uploaded |

**Milestone at end of Phase 1:** You can write a SQL query with a window function from memory, you hold 2 BI
certifications, your resume is US-market-ready, and your visa paperwork is filed.
